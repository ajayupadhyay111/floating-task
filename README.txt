============================================
  FloatTask - Floating Task Manager
============================================

SETUP (Pehli baar):
1. Python install karo: https://python.org (Add to PATH checkbox zaroor tick karo)
2. setup.bat double-click karo
3. run.bat double-click karo → App start!

DAILY USE:
- Purple circle dikhega screen pe
- Drag karke kahi bhi rakh do
- Click karo → tasks dikhenge
- Enter dabao → task add
- Checkbox click karo → task done
- X button pe hover karo → task delete

EXE BANANA (Optional - kisi aur ko dena ho):
- build_exe.bat double-click karo
- dist/FloatTask.exe mil jaayega
- Ye .exe kisi bhi Windows PC pe chalega (Python nahi chahiye)

DATA:
- Tasks save hote hain: C:\Users\<username>\floating_tasks_data.json
- Circle ki position bhi yaad rehti hai

ISSUES:
- Agar kuch galat ho to floating_tasks_data.json delete kar do, fresh start ho jaayega
